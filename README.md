# Videoclub - TP Final Estructuras de Datos

## Integrantes
Carina Ruiz, Hernan Alegre, Gisela Morales, Mariana Gimenez, Eric Ignacio Claros

## Cómo ejecutar
Desde la carpeta `proyecto estructuras de datos`:

    python main.py

## Estructura del proyecto
- `modelo/`: clases Pelicula y Cliente
- `servicios/`: carga y guardado de datos (JSON) y gestión del catálogo
- `UX/`: menú de consola
- `datos/`: peliculas.json y clientes.json
